# typetrace-cli

An alias of [`typetrace`](https://pypi.org/project/typetrace/): installing it installs `typetrace` (the same
version) and adds the command `typetrace-cli`, which is the same as `typetrace`.

```
uvx typetrace-cli init .
```

TypeTrace finds the code an AI coding agent needs: file:line pointers plus callers and callees, locally, over MCP.
Documentation: https://github.com/Atrix21/typetrace
