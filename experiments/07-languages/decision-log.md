# Experiment 07 decision log

- **E7-D01** · Scope: graph quality (does each edge point at the right code?), not retrieval. There are no ground-truth tasks for these languages, so no retrieval or agent claim is made for them.
- **E7-D02** · One tree-sitter engine with an adapter per language (`src/languages/syntactic.ts`), instead of one front-end per language: the resolution rules (this/self, declared types, imports, packages, return types) are shared, and only the syntax differs.
- **E7-D03** · JavaScript goes through the TypeScript compiler (`allowJs`, only when the corpus has JavaScript), not tree-sitter: the compiler already resolves CommonJS and ES modules and infers types.
- **E7-D04** · TypeScript and Python are untouched: graph and symbol-index hashes are identical before and after on targets/bench, psf/requests and pallets/flask. The running SWE-bench experiment (05) uses a frozen checkout and is unaffected either way.
- **E7-D05** · Grammars: newer Scala (0 of 29 files with errors, vs 19) and Kotlin (2 of 86, vs 11) builds vendored in `grammars/` (MIT, provenance in its README). Newer C, C++ and C# builds were tried and not adopted (no improvement for C/C++; C# had 18× more error nodes).
- **E7-D06** · First hand-check (12 verified + 6 guessed edges per repository) showed name-only guesses were often standard-library calls (`Integer.parseInt`, `Task.Run`, `push_back`, Ruby `include?`). Fixes: no guess when the receiver's declared type, or a class-like receiver name, is outside the repository; a list of colliding standard-library names; Go package-level variables and Swift modules resolved; Java, Kotlin and Scala share one type space (moshi verified calls 2,069 → 4,035); backtick-quoted Kotlin names.
- **E7-D07** · Chained calls are typed through declared return types (with `Option`, `Box`, `Optional`, `Future`, `shared_ptr`... unwrapped). gin verified calls 2,442 → 3,377; name guesses 1,300 → 331.
- **E7-D08** · Second hand-check: 300 edges (12 verified + 12 guessed per repository, express 12 verified), seeded by edge-id hash, judged against call sites and source (`results/hand-checked-run/hand-check.json`). Verified edges 151/156 correct; all 5 errors are names mis-nested after grammar parse errors.
- **E7-D09** · Guess policy set from E7-D08, threshold ≥ 50% correct: receiver guesses kept for Swift, Go, C#, Scala, Kotlin, C++; dropped for Rust, Ruby, Java, PHP. Bare-name guesses kept for C, C++, Rust; not used elsewhere (unmeasured). C++ namespace guesses dropped (0/3). The threshold was drawn on the same sample it was measured on (stated in the README limitations). Final counts: `results/final/`.
